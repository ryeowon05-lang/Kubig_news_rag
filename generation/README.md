# Generation / Claude API

This directory contains the generation stage of the Korean financial-news RAG pipeline.

## Files

- `prompt.py`: grounded prompt template. The model is instructed to answer only from retrieved news and cite `[뉴스N]`.
- `llm.py`: Claude Messages API adapter.
- `../rag.py`: connects retrieval -> prompt -> Claude -> answer + source metadata.

## Setup

From the project root:

```bash
uv add anthropic
```

Set the API key in your shell. Do not commit the real key.

PowerShell:

```powershell
$env:ANTHROPIC_API_KEY="YOUR_KEY"
```

macOS/Linux:

```bash
export ANTHROPIC_API_KEY="YOUR_KEY"
```

Optionally set the model:

```powershell
$env:CLAUDE_MODEL="claude-sonnet-4-6"
```

## Run the end-to-end pipeline

Make sure the Chroma index already exists, then:

```bash
uv run python rag.py "삼전 반도체 실적 전망은?"
```

The result is JSON containing:

- `question`
- `answer`
- `sources` (`news_number`, title, date, URL, stock names, similarity)

The source list is built from the retrieval results rather than generated by Claude, so the displayed URLs remain tied to the actual retrieved chunks.
